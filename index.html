Retail Shelf Stock Monitoring and SKU Gap Detection.

Problem
Spot empty shelf space and likely stock-outs from shelf images.
What I built
A computer-vision system for product detection, counting and shelf-gap identification.
How it works
Bounding-box localisation and histogram-based segmentation find the products, and K-Means clustering groups them by SKU. Stock trends over time feed a basic forecast that flags potential stock-outs.
Status
Project, Nov to Dec 2025.
Stack
Computer VisionK-MeansForecasting

An image classifier for chest X-rays that also shows which regions it relied on.

Problem
Detect pneumonia from chest X-ray images on an imbalanced dataset, and make the predictions inspectable.
What I built
A ResNet50-based classifier with Grad-CAM visual explanations.
How it works
The images are preprocessed and the classes balanced, then transfer learning is applied with data augmentation. Grad-CAM highlights the lung regions that drove each prediction.
Result
93.7% classification accuracy, working with 27,000 chest X-ray images.
Status
Academic project, Feb to Apr 2024.
Stack
TensorFlowResNet50Transfer LearningGrad-CAM

A question-answering assistant that answers only from official documents.

Problem
Answer admission, placement and scholarship questions from authenticated policy documents, while keeping processing offline.
What I built
An AI agent system that uses Retrieval-Augmented Generation over the policy documents.
How it works
PDFs are ingested and embedded, and FAISS vector search retrieves the relevant passages so that answers stay grounded in the documents. A local LLM hosted with Ollama handles generation, which keeps it offline, private and low-latency.
Status
Project, Nov to Dec 2025.
Stack
Agentic RAGEmbeddingsFAISSOllama

How I approach a problem

Four steps I keep coming back to. Each one points at work I have actually done.

Start with how the work is actually done

At Havoc Consultants I analysed recruitment workflows and found gaps in candidate tracking, follow-ups and pipeline visibility. At ClearDeals I documented sales, lead-management and backend workflows to find process gaps.

  • Recruitment workflow analysis at Havoc Consultants
  • Sales and lead-management workflow documentation at ClearDeals
  • Requirements turned into structured workflows and data requirements

Get the data into shape

Preprocessing comes before modelling. For the pneumonia classifier that meant preparing 27,000 chest X-rays and balancing the classes. For the ClearDeals lead scraper it meant turning scraped listings into structured data with Pandas.

  • Preprocessing and class balancing in Pneumonia Detection
  • Data augmentation in Pneumonia Detection
  • Structured data processing with Pandas in the ClearDeals lead scraper

Model, measure, then look inside

For the X-ray classifier I used transfer learning with ResNet50, measured classification accuracy, and used Grad-CAM to see which regions drove each prediction. For the shelf monitor I used K-Means to group products by SKU.

  • Transfer learning with ResNet50
  • Classification accuracy as the measure
  • Grad-CAM to inspect predictions
  • K-Means clustering for SKU grouping

Put it in a usable form and explain it

The ClearDeals lead scraper runs as a Streamlit app, and the interview bot is organised as backend workflows. At Ethika I helped design and present OPD benefit models to business stakeholders.

  • A Streamlit app for the lead scraper
  • Backend workflows for the interview bot
  • Benefit models presented to business stakeholders at Ethika
